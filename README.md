# Daymark

A lightweight to-do list that runs directly in your browser. No dependencies, build step, or server required.

## Use

Open `index.html` in a browser, enter a task, choose its priority and optional due date, then select **Add task**. Use the navigation to view all tasks, tasks due today, upcoming tasks, or completed tasks.

Tasks are saved in the browser's local storage, so they remain after reloading the page in the same browser. Clearing that browser's site data will remove them.

## Features

- Add tasks with low, medium, or high priority
- Set optional due dates and see overdue tasks
- Mark tasks complete or delete them
- Filter tasks by date and completion status
- Track today's completion progress
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` directly. The interface uses Google Fonts when an internet connection is available and falls back to system serif and sans-serif fonts otherwise.
